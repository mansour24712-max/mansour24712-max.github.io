# Mini guida Markdown

Markdown è un modo semplice per dare struttura a un testo. In LAB01 usa soltanto
questi esempi.

## Titoli

Scrivi un cancelletto e uno spazio per un titolo grande:

```markdown
# Il mio titolo
```

Scrivi due cancelletti e uno spazio per un sottotitolo:

```markdown
## Un sottotitolo
```

## Elenchi

Metti un trattino, uno spazio e poi ogni voce:

```markdown
- Informatica
- Musica
- Sport
```

## Grassetto

Metti due asterischi prima e dopo le parole importanti:

```markdown
**Questa frase è importante.**
```

## Link

Scrivi il testo tra parentesi quadre e l'indirizzo tra parentesi tonde:

```markdown
[Il mio profilo GitHub](https://github.com/tuo-username)
```

> Prima di confermare una modifica, guarda sempre l'anteprima se è disponibile.
> Se titolo, elenco o link non appaiono come previsto, correggi il testo e
> ricontrolla.
