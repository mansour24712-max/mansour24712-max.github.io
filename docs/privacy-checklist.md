# Checklist privacy — prima di pubblicare

Il tuo profilo è pubblico. Pubblica ciò che saresti tranquillo/a a mostrare
contemporaneamente a un compagno, a un docente e a una futura azienda.

Prima di confermare una modifica, rileggi il testo e verifica tutti i punti.

- [ ] Non ho inserito il mio indirizzo di casa.
- [ ] Non ho inserito il mio numero di telefono.
- [ ] Non ho inserito password.
- [ ] Non ho inserito codici 2FA.
- [ ] Non ho inserito Recovery Code.
- [ ] Non ho inserito file KeePassXC.
- [ ] Non ho inserito token o API key.
- [ ] Non ho inserito informazioni familiari o sensibili non necessarie.
- [ ] Non ho inserito fotografie, dati o link di altre persone senza il loro consenso.

> 🛑 CHECKPOINT
> Se anche un solo punto non è rispettato, non pubblicare: elimina o sostituisci
> l'informazione e chiedi aiuto al docente se hai un dubbio.
