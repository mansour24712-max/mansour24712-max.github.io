## Dove scrivere

Nel nostro corso useremo questa convenzione didattica:

| Se hai… | Usa… |
| --- | --- |
| un'attività concreta, un problema da correggere o un miglioramento | **Issues** |
| una domanda, un confronto, una richiesta di aiuto o una proposta | **Discussions** |

Per LAB01 usa queste Discussions:

- **👋 Presentiamoci tecnicamente** per la presentazione;
- **🆘 Aiuto LAB01** per domande e problemi;
- **💡 Idee e progetti che vorremmo realizzare** per proposte facoltative.

## Chiedere aiuto: le 3P

Scrivi sempre:

1. **PROBLEMA** — Cosa volevi ottenere?
2. **PROVA** — Che cosa è successo?
3. **PROCESSO** — Che cosa hai già tentato?
